# 🎬 Movie Night — سینمای دو نفره

یک وب‌اپ برای تماشای همزمان (Watch Party) فیلم توسط دو نفر، با یک صحنه‌ی سه‌بعدیِ اتاق خواب که هر دو نفر روی تخت دراز کشیده‌ان و به تلویزیون نگاه می‌کنن، امکان چت زنده، و یک سینی خوراکی (ذرت، چیپس، پفک، بستنی، پیتزا) که می‌شه خورد یا به پارتنر داد.

بک‌اند این نسخه کاملا روی **Cloudflare Workers + Durable Objects** اجرا می‌شه — کاملا رایگان، بدون نیاز به کارت بانکی.

## ساختار پروژه

```
couple-watch-party/
├── worker/     ← بک‌اند: Cloudflare Worker + Durable Object (سینک پخش، چت، حضور، خوراکی)
├── client/     ← فرانت‌اند: React + Vite + react-three-fiber (صحنه‌ی سه‌بعدی)
└── .github/workflows/deploy-pages.yml   ← بیلد و پابلیش خودکار client روی GitHub Pages
```

## چرا Cloudflare Workers، و چرا بدون کارت بانکی ممکنه

- **Workers** (پلن رایگان): ۱۰۰ هزار ریکوئست در روز، بدون کارت بانکی.
- **Durable Objects با بک‌اند SQLite**: از آوریل ۲۰۲۵ روی پلن رایگان Workers هم در دسترسه (بدون کارت بانکی) — دقیقا همینه که برای نگه‌داشتن وضعیت اتاق (کی آنلاینه، ویدیو کجاست، پلی/پاز) و مدیریت اتصال‌های WebSocket استفاده شده. با `WebSocket Hibernation API` هم پیاده‌سازی شده، یعنی وقتی هیچ پیامی رد و بدل نمی‌شه هزینه‌ی duration صفره.
- **آپلود فایل روی سرور عمداً حذف شده**: سرویس آبجکت‌استوریج Cloudflare (R2) حتی توی پلن رایگانش هم ثبت کارت بانکی رو لازم داره (خود Cloudflare اینو الزامی کرده، حتی اگه چیزی ازت کم نشه). برای اینکه کل پروژه بدون کارت بانکی بمونه، پخش فقط از طریق **لینک مستقیم** ویدیو انجام می‌شه (توضیح کامل در بخش «انتخاب فیلم» پایین‌تر).

اگه بعدا خواستی و کارت بانکی هم داشتی، اضافه کردن آپلود واقعی با R2 کار بزرگی نیست (یک بایندینگ R2 به `worker/wrangler.toml` و یک روت آپلود در `worker/src/index.js`)، ولی توی این نسخه عمدا کنار گذاشته شده تا صفر هزینه/صفر کارت بمونه.

## اجرای محلی (روی کامپیوتر خودت)

```bash
# ترمینال ۱ — بک‌اند (Worker)
cd worker
npm install
npm run dev          # wrangler dev، روی http://localhost:8787

# ترمینال ۲ — فرانت‌اند
cd client
npm install
npm run dev           # روی http://localhost:5173، به‌صورت پیش‌فرض به localhost:8787 وصل می‌شه
```

دو مرورگر (یا یک مرورگر عادی + یک incognito) باز کن، هر کدوم یه دستگاه رو انتخاب کن (ملیسا / شایان) و تست کن.

## دیپلوی

### ۱) بک‌اند روی Cloudflare Workers (رایگان)

1. یه حساب رایگان Cloudflare بساز: https://dash.cloudflare.com/sign-up — نیازی به کارت بانکی نیست.
2. توی پوشه‌ی `worker/`:
   ```bash
   cd worker
   npm install
   npx wrangler login    # مرورگر باز می‌شه، حساب Cloudflare رو وصل کن (رایگان، بدون کارت)
   npm run deploy        # یعنی wrangler deploy
   ```
3. خروجی یه آدرس مثل این بهت می‌ده:
   ```
   https://couple-watch-party.YOUR-SUBDOMAIN.workers.dev
   ```
   این آدرس رو نگه دار — بک‌اند شماست.

> نکته: اولین بار که `wrangler deploy` رو می‌زنی، به‌خاطر تنظیمات `[[migrations]]` توی `wrangler.toml`، Durable Object با بک‌اند SQLite (سازگار با پلن رایگان) ساخته می‌شه. لازم نیست چیزی رو دستی تغییر بدی.

### ۲) فرانت‌اند روی GitHub Pages (خودکار با GitHub Actions)

1. یه مخزن جدید توی گیت‌هاب بساز و کل این پوشه رو push کن.
2. توی تنظیمات مخزن: **Settings → Pages → Source** رو روی **GitHub Actions** بذار.
3. توی **Settings → Secrets and variables → Actions → Variables** دو متغیر بساز (Repository variable، نه Secret — چون مقدار محرمانه نیست):
   - `VITE_WORKER_URL` = همون آدرس Worker که بالا گرفتی، مثلا `https://couple-watch-party.YOUR-SUBDOMAIN.workers.dev`
   - `VITE_BASE` = `/اسم-مخزن/` (دقیقا اسم ریپو، با اسلش اول و آخر — مثلا `/couple-watch-party/`)
4. یه push به برنچ `main` بزن (یا از تب Actions، workflow «Deploy client to GitHub Pages» رو دستی اجرا کن).
5. بعد از چند ثانیه، سایتت روی `https://YOUR-USERNAME.github.io/اسم-مخزن/` بالا میاد.

اگه ترجیح می‌دی دستی بیلد کنی:
```bash
cd client
VITE_WORKER_URL=https://couple-watch-party.YOUR-SUBDOMAIN.workers.dev VITE_BASE=/REPO_NAME/ npm run build
```
خروجی توی `client/dist` ساخته می‌شه؛ می‌تونی با پکیج `gh-pages` هم روی برنچ `gh-pages` پوشش کنی.

> نکته: چون دو‌نفرینه‌ی این اپلیکیشنه، لازم نیست چند روم پشتیبانی بشه؛ Durable Object فعلی یک روم مشترک ساده داره (`ROOM.idFromName("couple-room")`). اگه خواستی چند جفت هم‌زمان ازش استفاده کنن، کافیه توی `worker/src/index.js` به‌جای اسم ثابت، یه room-code از querystring بگیری و `idFromName(roomCode)` بزنی.

## انتخاب فیلم — فقط لینک مستقیم

چون آپلود فایل روی این نسخه‌ی بدون کارت‌بانکی وجود نداره، باید یه **لینک مستقیم** به فایل ویدیو بدی:
- یه فایل `mp4`/`webm` که جایی آپلودش کردی (مثلا Google Drive با لینک مستقیم به فرمت `https://drive.google.com/uc?export=download&id=FILE_ID`، یا هر هاست رایگان دیگه‌ای که لینک مستقیم فایل می‌ده)
- یا لینک یک استریم `m3u8`

این راهنما توی خود اپ هم، زیر فرم انتخاب فیلم («لینک مستقیم از کجا بیارم؟») هست.

### محدودیت مهم درباره‌ی لینک‌های `vlc://`

لینک‌هایی با پروتکل `vlc://` یا اسکیم‌های مشابه، یک برنامه‌ی جدا (VLC) رو روی سیستم عامل باز می‌کنن — چیزی که مرورگر و جاوااسکریپت هیچ کنترلی روش ندارن (نه پلی/پاز، نه سیک، نه حتی اطلاع از وضعیتش). به همین دلیل سینک واقعی فقط برای این‌ها ممکنه:
- لینک مستقیم به یک فایل ویدیویی یا استریم (mp4/webm/m3u8) که مرورگر بتونه در تگ `<video>` پخشش کنه

اگه لینک `vlc://` وارد کنی، سایت تلاش می‌کنه اون رو باز کنه ولی به‌صراحت بهت هشدار می‌ده که سینک نمی‌شه.

## قابلیت‌ها

- ✅ انتخاب دستگاه (ملیسا / شایان) در ورود، ذخیره در `localStorage`
- ✅ پخش از لینک مستقیم ویدیو
- ✅ سینک پلی/پاز/سیک بین دو کاربر با هارت‌بیت هر ۴ ثانیه برای اصلاح دریفت — از طریق یک WebSocket خام به Durable Object (بدون socket.io)
- ✅ اتصال مجدد خودکار در صورت قطعی شبکه (با backoff)، و sync دوباره‌ی وضعیت بعد از وصل شدن
- ✅ چت زنده کنار فیلم
- ✅ صحنه‌ی سه‌بعدی: اتاق خواب، تخت، دو کاراکتر دراز کشیده، تلویزیون روی دیوار که واقعاً ویدیوی در حال پخش رو (به‌صورت texture) نشون می‌ده، نورپردازی گرم (چراغ‌خواب) + نور آبی صفحه‌ی تلویزیون
- ✅ سینی خوراکی با ۵ آیتم (ذرت، چیپس، پفک، بستنی، پیتزا) — کلیک روی هرکدوم → «خودم می‌خورم» یا «بده به پارتنر» (با انیمیشن پرواز و واکنش کاراکتر طرف مقابل، سینک‌شده روی هر دو دستگاه)
- ✅ دکمه‌ی تمام‌صفحه: سوییچ بین دیدن صحنه‌ی سه‌بعدی (روی تخت) و دیدن فقط ویدیو تمام‌صفحه، بدون قطع پخش

## توسعه‌ی بیشتر (پیشنهادی)

- اگه یه روز کارت بانکی داشتی و خواستی آپلود واقعی فایل هم اضافه کنی: یه بایندینگ R2 به `worker/wrangler.toml` اضافه کن و یه روت `POST /api/upload` که فایل رو با `env.BUCKET.put()` ذخیره کنه و لینکش رو برگردونه.
- اضافه کردن صدای مشترک (voice chat) با WebRTC
- ری‌اکشن‌های ایموجی روی صحنه (❤️ 😂 😱) هنگام تماشا
- چند room-code برای پشتیبانی از چند زوج هم‌زمان (توضیح داده شده در بخش دیپلوی)
- بارگذاری مدل‌های سه‌بعدی واقعی (glTF) به‌جای اشکال رویه‌ای، برای ظاهر واقعی‌تر
